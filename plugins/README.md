## 一键奶人包是什么

**一条命令搞定酒馆部署**，装好就能玩，不用自己折腾环境。没魔法也能装（内置国内源自动切换）。

包含两样东西：

### ① 酒馆本体 (SillyTavern)

- 全球社区都在用的开源角色扮演聊天界面，让你在手机上拥有专属 AI 聊天伴侣
- 锁定 **v1.18.0** 稳定版，不会因为版本漂移出问题
- 内置国内 + 国外双源，失败自动切换，全程不用你操心

### ② 酒馆助手 (Tavern Helper)

- 给酒馆加 buff 的增强插件
- 安装时可选装：跑 `bash -c "$(curl ...)"` 方式会弹出菜单，选 `[1]` 即可一起装好
- 装完去酒馆「扩展」面板勾选启用

## 还需要别的插件吗？

**不用。装完即可开玩**，一键奶人包不依赖任何额外插件。

如果之后想扩展玩法（TTS 语音、生图、表情包等），酒馆的插件生态很丰富，可以自己探索，也可以在群里和姐妹们交流。
