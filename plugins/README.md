## 安装方法

1. 打开酒馆 → 左侧「扩展」图标
2. 进入「下载扩展与插件」或「插件市场」
3. 搜索上方关键词 → Install
4. 安装后重启酒馆

> 插件市场需要酒馆已登录/连接网络。若插件市场加载慢，可用加速镜像（QQ 群内提供）。

## 手机端注意

- Termux 下建议装：Silero TTS（本地）、Summarize（摘要防失忆）、Vector Storage（向量记忆）
- 手机性能有限，重插件（生图/动画）建议 PC 端使用
